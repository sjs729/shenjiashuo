申家硕《高级网页设计》
课堂实践

这里汇总了本课程每次课堂练习的成果页面。从最基础的 HTML 标签， 到结构完整的自我介绍网页，再到 CSS 的层叠继承与盒模型， 以及用列表结构做的上图下文图片卡片布局（Grid 与 Flex 两种写法）， 还有用语义标签搭骨架、用 transform 与 transition 做卡片动画的作业页， 以及用 CSS3 结构伪类选择器配合渐变、变形与关键帧动画做的一组方块效果， 加上用 SVG symbol 图标配合一小段 JavaScript 做的底部标签栏， 还有 JavaScript 对象的属性、遍历与引用赋值练习， 都会以超链接形式收录在本页中，方便随堂演示与课后回看。
