Task 01 · Prompt Engineering

一句话说不清，
AI 就会猜给你看

老师要的配置有四条：无缝循环、3.2 秒自动翻页且手动后不停、圆点分页器可点击、初始效果 cube。 下面两个轮播都在真实运行——左边是第一轮提示词喂出来的，右边是第二轮。差别只有一个键。 别听我说，点一下左边和右边的圆点，看读数。

需求 4 项 迭代轮次 2 轮 差异参数 1 个 验收方式 真实点击 + 读数
01

同一句需求，两种翻译

两个轮播的 HTML 完全一样，只有 JS 配置差一个 clickable。点圆点试试，下面那行读数会告诉你发生了什么。

第 1 轮 漏了需求

圆点只能看，不能点

提示词里只写了"圆点分页器"。AI 理解为"把圆点画出来"，于是只给了 el，没给 clickable。

02

把中文需求翻译成参数

答辩时最容易被追问的是"这句话对应哪个参数"。这张表就是交卷前该背下来的东西。

老师的要求 对应参数 为什么是它
无缝循环 loop: true 首尾相接，最后一张再往后翻回到第一张；不开的话翻到头就停住
3.2 秒自动翻页 autoplay: { delay: 3200 } delay 的单位是毫秒，3.2 秒 = 3200
手动操作后不停 autoplay.disableOnInteraction: false 默认是 true，一拖就永久停机；这一条最容易被漏
圆点分页器可点击 pagination: { el, clickable: true } el 只决定画在哪，clickable 才决定能不能点
初始效果 cube effect: 'cube' 效果只在初始化时读取，所以必须写在 new 的配置里
03

两轮提示词，差在哪

第一轮是"翻译需求"，第二轮是"补漏洞"。真正让 AI 改对动作的，是说清楚"点了之后应该发生什么"。

第 1 轮 · 原文

给 Swiper 写一个初始化配置，要求：无缝循环、3.2 秒自动翻页、手动操作后不停止、圆点分页器、初始效果 cube。
  • "圆点分页器"只是名词，没说它要能点
  • AI 按最短路径实现：画出来就算完成
  • 结果：四个需求里有一个是"看着对、用着错"

第 2 轮 · 原文

上一版缺一条：分页器的圆点必须可以点击直接跳转到对应那张，不是只能看。其它要求不变。
  • 把名词换成动作："点击 → 跳转"
  • 同时排除误解："不是只能看"
  • 明确改动范围："其它要求不变"，避免它顺手改坏别的
答辩要点：被问到"AI 第一次错在哪"，标准答案是——它没有错，是需求描述只含有名词、不含动作。 pagination.el 和 pagination.clickable 是两个键，前者决定位置、后者决定行为， 中文里"分页器"一个词同时盖住了这两件事，AI 只能挑一个实现。这不是 AI 笨，是翻译丢了信息。
04

四项需求的验收记录

老师要求"亲自粘进页面验证每项需求"。下面是逐项实测的做法与结论，不是复述配置。

需求 怎么验的 结论
循环 停在最后一张，再点一次下一张 回到第 1 张，通过
3.2 秒自动翻 静置不动，读 realIndex 前后变化 约 3.2 秒后索引 +1，通过
手动后不停 手动滑动一次，再读 autoplay.running 仍为 true，通过
圆点可点击 点第 3 个圆点，读 realIndex 是否变化 第 1 轮不变（失败）／第 2 轮跳到 2，通过
初始 cube 读实例的 params.effect 等于 'cube'，通过
