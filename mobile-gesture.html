00

效果说明

本页实现的是移动端最基础的一种手势：横向滑动切换内容。四道菜是一组横向排列的卡片， 手指左右划动时整条卡片跟着平移，像翻相册一样。

具体表现

① 在卡片上左右滑动，松手即切换：左滑看下一道，右滑回上一道，切换带 0.3 秒滑动过渡；
② 底部实时显示 “第 N / 4 张”，中间四个圆点标出当前位置，当前那个变长变红；
③ 滑到第 1 张继续右滑，或第 4 张继续左滑，卡片不动，下方弹出一句提示， 1.6 秒后自动淡出；
④ 右侧还会显示本次手势的判定结果（如“左滑 · 下一张”），方便确认方向识别对不对。

操作步骤（验收时照着做）

① 轻轻点一下卡片 → 不切换，说明阈值把误触过滤掉了；
② 向左划一段（超过 40px）→ 切到第 2 张；
③ 继续左划两次 → 到第 4 张，再左划 → 提示“已经是最后一张了”，卡片不动；
④ 向右划两次 → 回到第 1 张，再右划 → 提示“已经是第一张了”；
⑤ 在卡片上竖向划动 → 页面跟着上下滚，卡片不切换。
01

三个验收点怎么保证

① 短距离误触不会切换

在 touchend 里算位移，横纵位移都小于 40px 就直接返回， 当作点击处理。手指按下时几乎不可能完全不动，没有阈值会把几像素的抖动误判成滑动。

② 快速连续滑动不会跳两张

记录上一次切换的时间戳，距离上次不足 300ms 就忽略本次手势。 动画本身 0.3s，冷却时间与之对齐，手再快也只会一张一张走。

③ 拖动时页面不会跟着上下滚

容器加 touch-action: pan-y——横向手势归我，纵向交给浏览器。 这样往上滑页面照常滚动，往左右滑才切卡片。如果写成 none， 整块区域连纵向滚动都会被吃掉。
02

核心逻辑

只用了 touchstart 与 touchend 两个事件——判断方向不需要跟手的中间过程。

// 记起点
sjs_stage.addEventListener('touchstart', function (e) {
  const t = e.touches[0];
  sjs_startX = t.clientX;
  sjs_startY = t.clientY;
}, { passive: true });

// 抬手时结算
sjs_stage.addEventListener('touchend', function (e) {
  // 必须用 changedTouches：touches 里已经没有抬起的那根手指
  const t = e.changedTouches[0];
  const dx = t.clientX - sjs_startX;
  const dy = t.clientY - sjs_startY;

  // ① 阈值：横纵都小于 40 → 当作点击，不切换
  if (Math.abs(dx) < 40 && Math.abs(dy) < 40) return;

  // ② 冷却：距上次切换不足 300ms 直接忽略
  if (Date.now() - sjs_lastTime < 300) return;

  // ③ 只处理横向，纵向滑动不抢页面滚动
  if (Math.abs(dx) < Math.abs(dy)) return;

  sjs_lastTime = Date.now();
  sjs_go(dx > 0 ? -1 : 1);   // 右滑上一张，左滑下一张
});
