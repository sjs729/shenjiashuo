七种效果随心换effect 参数 + 进阶：按钮实时切换

改一个 effect 参数，轮播立刻换一种"性格"：slide / fade / cube / coverflow / flip / cards，第七种 creative 是课堂没讲的自定义变换。上面 7 个按钮都用 btn.dataset.fx 读取效果名，点击后由 JS 销毁旧实例、重建新实例。

✍️ 任务 4 要求

基础分：初始化 #wySw4，实现循环 + 自动播放（3.2 秒）+ 圆点分页器（#wyPag4），初始效果为 'cube'，动画时长 800 毫秒。

进阶分：补全按钮点击事件中的 TODO——实现点击按钮切换效果。提示：Swiper 动态换 effect 不能只改参数，需要先销毁旧实例再重建（destroy + new）。

超纲加分：第 7 个按钮 creative（电影墙）来自课堂未讲的第 7 种效果，配合键盘 ← → 控制一起体验。

⭐ 验证标准：基础分——轮播自动翻页；进阶分——点 cube 按钮变 3D 立方体、点 fade 变淡入淡出；加分项——点 creative 变电影选片墙，轮播在视口内时按方向键能翻页

第二关 ⭐⭐⭐ 已交付

creative 仿写：课堂没讲的第 7 种效果

参照官方示例 swiper/demo/257-effect-creative.html，读懂 creativeEffect，给演示四新增第 7 个按钮「creative 电影墙」。

  • prev 管「已经翻过去的那一张」：负的 X 位移往左退，负的 Z 值往远处缩，rotate[2] 让它带一点倾角。
  • next 管「下一张怎么进来」：正的 X 位移从右侧推进，正的 Z 值往前压，配合 scale 与 opacity 做入场。
  • 作答位置：上面演示四按钮组最后一个，点它即可切换。

⚡ 答辩准备：transform 里的百分比相对的是这张 slide 自己的宽度——不是容器，也不是图片。实测：容器 600px、一屏三张时 slide 宽 200px，写 50% 只位移 100px。

第三关 ⭐⭐⭐ 已交付

综合创作 + 技术答辩：超纲加分项

① 为光影展添加第六件展品爱达·魔都号（2024 年 1 月首航，首艘国产大型邮轮）；② 加一个课堂没讲过的 Swiper 能力。

  • 展品：已加到演示四 slide 列表末尾，16:9 横向配图，说明文字与其余五件同格式。
  • 超纲能力：选了 thumbs 缩略图联动——来自官方 300 号 demo，课堂未讲，同学也没用过。
  • 实现要点：用两个独立实例，先建缩略图再建主图，通过 thumbs: { swiper: 实例 } 绑定；缩略图必须加 watchSlidesProgress。

⚡ 答辩准备：thumbs 传的是实例对象不是选择器，因为运行时要靠它调用 slideTo 同步索引；且它天生双向，主图翻页缩略图会自己跟。
