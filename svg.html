SVG 图标

图标用 <svg> > <symbol> 定义成符号表，页面上用 <use href="#icon-xxx"> 引用；点击底部标签栏切换选中状态， 由一小段 JavaScript 负责增删 active 这个类。页面底部就是成品，滚动看看。

这一页练了什么

  • SVG symbol + use：图标只写一遍，多处复用；viewBox="0 0 24 24" 决定图标自身的坐标系。
  • 图标跟随文字颜色：.icon 上写 fill: none; stroke: currentColor;，文字色一变图标就跟着变，不用给图标单独配色。
  • 固定定位：标签栏 position: fixed; bottom: 0;，滚动页面时停在窗口底部；它不占文档流，所以主体区要补下边距。
  • class 切换：querySelectorAll 拿到全部标签，classList.remove 清掉旧的选中态，再给当前这一项 classList.add('active')。
<svg class="icon" aria-hidden="true">
    <use href="#icon-browser"></use>
</svg>

.icon { fill: none; stroke: currentColor; }   /* 颜色跟着文字走 */
.tab-item.active { color: #1f4fd8; }          /* 选中态只改文字色 */
